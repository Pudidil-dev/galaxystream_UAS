## 1. Pendahuluan

### Apa itu GalaxyStream?

GalaxyStream adalah aplikasi desktop entertainment hub yang memungkinkan Anda untuk:

- **Menonton Drama** - Drama Korea, China, dan konten short video dari berbagai sumber
- **Menonton Anime** - Anime dengan subtitle Indonesia dari Otakudesu dan Kuramanime
- **Membaca Komik** - Manhwa dan manga digital dengan fitur zoom

### Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| Multi-Sumber | Akses konten dari 7+ sumber berbeda |
| Autentikasi | Login aman dengan email atau Google |
| Riwayat | Lanjutkan tontonan dari posisi terakhir |
| Tema Gelap | Antarmuka premium dengan tema gelap |
| Offline Cache | Gambar poster disimpan lokal untuk akses cepat |

## 3. Instalasi Aplikasi

### Metode 1: Menggunakan Installer (Direkomendasikan)

1. **Download** file `GalaxyStream_Setup_v4.exe`
2. **Jalankan** installer dengan double-click
3. **Ikuti** petunjuk instalasi:
   - Pilih lokasi instalasi (default: `C:\Program Files\GalaxyStream`)
   - Pilih opsi tambahan:
     - [ ] Buat shortcut di Desktop
     - [ ] Izinkan akses firewall untuk server lokal (port 3001)
4. **Tunggu** proses instalasi selesai
5. **Selesai** - Klik "Finish" untuk menutup installer

### Metode 2: Portable (Tanpa Instalasi)

1. **Download** file `GalaxyStream_Portable.zip`
2. **Extract** ke folder pilihan Anda
3. **Jalankan** `GalaxyStream.exe`

### Catatan Penting

> **Antivirus**: Beberapa antivirus mungkin memblokir aplikasi karena mengandung server lokal. Tambahkan pengecualian untuk folder GalaxyStream jika diperlukan.

## 5. Registrasi dan Login

### 5.1 Membuat Akun Baru

1. Buka aplikasi GalaxyStream
2. Pada halaman login, isi:
   - **Email**: Masukkan alamat email valid
   - **Password**: Minimal 6 karakter
3. Klik tombol **"Create Account"**
4. **Cek email Anda** untuk link konfirmasi
5. Klik link konfirmasi di email
6. Kembali ke aplikasi dan **login** dengan kredensial Anda

#### Contoh:
```
Email: user@example.com
Password: ********

[Create Account] <- Klik ini
```

#### Pesan Sukses:
```
✓ Account created!

1. Check your email for confirmation link
2. Click the confirmation link
3. Close the browser tab (ignore 'localhost' error)
4. Return here and login with your credentials
```

### 5.2 Login dengan Email

1. Masukkan **Email** yang sudah terdaftar
2. Masukkan **Password**
3. Klik tombol **"Sign In"**

### 5.3 Login dengan Google

1. Klik tombol **"Sign in with Google"**
2. Browser akan terbuka ke halaman login Google
3. Pilih akun Google Anda
4. Berikan izin yang diminta
5. Setelah sukses, browser akan menampilkan "Login selesai"
6. Kembali ke aplikasi - Anda sudah login!

### 5.4 Logout

1. Klik **ikon profil** di pojok kanan atas
2. Pilih **"Logout"** dari menu dropdown
3. Anda akan kembali ke halaman login

## 14. Pemecahan Masalah

### 14.1 Masalah Login

#### "Supabase client not configured"
**Solusi**:
- Pastikan koneksi internet aktif
- Restart aplikasi

#### "Invalid email or password"
**Solusi**:
- Periksa kembali email dan password
- Pastikan akun sudah dikonfirmasi via email

#### "Email not confirmed"
**Solusi**:
- Cek inbox email Anda
- Cek folder spam
- Klik link konfirmasi di email
- Coba login kembali

#### Google OAuth tidak redirect
**Solusi**:
- Pastikan browser default bisa dibuka
- Coba tutup dan buka ulang aplikasi
- Pastikan port 8765 tidak diblokir firewall

### 14.2 Masalah Video

#### Video tidak mau diputar
**Solusi**:
- Periksa koneksi internet
- Coba episode lain
- Coba sumber konten lain
- Pastikan libmpv terinstall

#### Video buffering terus
**Solusi**:
- Periksa kecepatan internet
- Coba kualitas lebih rendah (jika tersedia)
- Tutup aplikasi lain yang menggunakan internet

#### "No stream URL found"
**Solusi**:
- Episode mungkin tidak tersedia
- Coba episode lain
- Coba sumber konten lain

### 14.3 Masalah Anime

#### "wajik-anime-api not found"
**Solusi**:
- Pastikan file `wajik-anime-api.exe` ada di folder aplikasi
- Restart aplikasi
- Jalankan aplikasi sebagai Administrator

#### Anime tidak loading
**Solusi**:
- Pastikan server lokal berjalan (port 3001)
- Cek apakah antivirus memblokir server
- Tambahkan pengecualian firewall untuk port 3001

### 14.4 Masalah Gambar

#### Poster tidak muncul
**Solusi**:
- Periksa koneksi internet
- Tunggu beberapa saat (loading async)
- Coba switch source dan kembali

#### Cache penuh
**Solusi**:
- Switch source untuk clear cache otomatis
- Hapus folder `cache` secara manual
- Lokasi cache: `%LOCALAPPDATA%\GalaxyStream\cache`

### 14.5 Masalah Umum

#### Aplikasi crash saat startup
**Solusi**:
1. Jalankan dari command prompt untuk lihat error:
   ```cmd
   cd "C:\Program Files\GalaxyStream"
   GalaxyStream.exe
   ```
2. Reinstall aplikasi
3. Update Windows

#### Aplikasi lambat
**Solusi**:
- Tutup aplikasi lain
- Clear cache dengan switch source
- Restart aplikasi

#### Aplikasi freeze
**Solusi**:
- Tunggu beberapa saat
- Jika tetap freeze, tutup via Task Manager
- Restart aplikasi

## 15. FAQ

### Q: Apakah GalaxyStream gratis?
**A**: Ya, GalaxyStream gratis untuk digunakan. Ini adalah proyek akademik untuk mata kuliah Pemrograman Visual.

### Q: Apakah perlu membuat akun?
**A**: Ya, akun diperlukan untuk mengakses aplikasi. Anda bisa mendaftar dengan email atau login dengan Google.

### Q: Bagaimana cara mendapatkan token API?
**A**: Token API diperlukan untuk beberapa sumber seperti NetShort dan Melolo. Anda perlu mendapatkan token dari penyedia API masing-masing.

### Q: Apakah konten tersedia offline?
**A**: Tidak, GalaxyStream membutuhkan koneksi internet untuk streaming konten. Hanya gambar poster yang di-cache secara lokal.

### Q: Bagaimana cara update aplikasi?
**A**: Download versi terbaru dari sumber resmi dan install ulang. Data login Anda akan tetap tersimpan.

### Q: Apakah tersedia untuk Mac atau Linux?
**A**: Saat ini GalaxyStream hanya tersedia untuk Windows. Versi untuk platform lain sedang dalam pertimbangan.

### Q: Konten tidak tersedia di sumber tertentu?
**A**: Ketersediaan konten tergantung pada API pihak ketiga. Jika konten tidak tersedia, coba sumber lain.

### Q: Bagaimana cara melaporkan bug?
**A**: Laporkan bug melalui:
- GitHub Issues (jika repo publik)
- Kontak developer

### Q: Data saya aman?
**A**:
- Password di-hash oleh Supabase
- Tidak ada data sensitif yang disimpan secara lokal selain session token
- Komunikasi menggunakan HTTPS

### Q: Berapa penyimpanan yang dibutuhkan?
**A**:
- Instalasi: ~500 MB
- Cache gambar: Bervariasi (auto-clear saat ganti sumber)
- Total rekomendasi: 1 GB
